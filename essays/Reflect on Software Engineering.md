## Intro

Before I took this class my knowledge on overall web development was very little. I dabbled in a little HTMl and Javascript, but never really made a coherent website. This class made me learn all those in a short amount of time which really challenged me. It was really fast paced with a lot of work.

## Configuration Management

In this class I learned how to configure and manage development. Particularly the most popular one I can think of is GitHub. Before this class I pretty much had zero knowledge on GitHub and thought it was very confusing to navigate. It was kind of a daunting task learning it and so I never really tried. This class made the learning process a whole lot smoother. Now I know a decent amount of GitHub to the point where if I don't know something, I can just look up a video and would probably understand it in its first run through compared to what I think would happened before where I wouldn't understand at all. Now I know how to properly manage and track software.

## Development Environments

For most coders when they think of development environments, IDEs come to mind. Though this is probably the most notable example, there are other tools/development environments that devs can use to expand and test their software. For example, in most web browsers there is an option to select more tools when viewing a website. When you click more tools it then shows you an option to open developer tools. This tool can help you identify problems that a website might have and you can build from that. I learned to do this because of the final project in this class. There were issues with the group project and after researching, I heard this was a great way to analyze and find the problems within your program. Now this is only one example of a development environment that software engineers can use, but there is a whole plethora of other tools out there. 

## Conclusion

Overall this class gave me a great headstart on software engineering and taught me a lot of good lessons. I feel much more experienced than I was before and even though I feel it was quite rushed, it gave me a good perspective on the software engineering world.
