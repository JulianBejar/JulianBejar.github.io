  When I first started my coding journey back during ICS 111 (not including previous coding projects that I had done before), I knew sometime down the line I would need to learn HTML and CSS as I heard those were too pretty prevalent languages to know in the coding scene. Now at the time I had no idea what either was and assumed that all code had a sort of design feature to it that can be put on websites easily with something like a click of a button. Come to find out that HTML and CSS are both necessary components for design and engineering.

  During this class is when I first learned all about HTML and CSS. I had dabbled in it before, but it was nothing ever serious and I did not understand it well at all. In fact I thought with all the symbols like <> and / made it look really confusing. Now after learning more about it in this class, I don't think it's as confusing as I made it out to be and that is just how the language is structured. There's also a lot of freedom in this language compared to your more standard programming languages such as JAVA and JAVASCRIPT.

  My learning process of HTML and CSS was very slow and I still don't understand a lot of it now, but it was very interesting to see how my code came out to look so nice visually which I had never properly had before. In previous classes it was just simple interfaces or text boxes that had no life to it which is the opposite to HTML and CSS. The implementation of bootstrap was also really nice to learn as it added more features and appeal when coding which often saved a lot of time compared to just using raw HTML and CSS. There are a lot of reusable components such as the navbar which was one of the major sections of this module. Now what I do wonder is although HTML and CSS provide a nice framework of web application and design, how can we implement actual code such as Javascript because other than just looking appealing and maybe leading to a couple links, the websites we make with HTML don't actually have a proper function yet. Overall, I look forward to see how learning more about this pans out in the future.
